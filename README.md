# Проект тестирования "Яндекс.Самокат"

Этот проект содержит автотесты для учебного сервиса "Яндекс.Самокат". Тесты разработаны с использованием `pytest` и автоматизируют сценарии тестирования основных функций сервиса. Отчеты о выполнении тестов генерируются с помощью Allure.

## Структура проекта

### Папка locators

- **home_page_locators.py**: содержит все необходимые локаторы для элементов на главной странице сервиса "Яндекс.Самокат".
- **order_page_locators.py**: включает локаторы для элементов на странице заказа самоката.
- **yandex_page_locators.py**: хранит локатор элемента на главной странице "Яндекс.Дзен".

### Папка pages

- **base_page.py**: в этой папке находятся методы, которые управляют веб-драйвером и содержат общие функции, используемые на страницах.
- **home_page.py**: содержит методы, обеспечивающие взаимодействие с главной страницей сервиса "Яндекс.Самокат".
- **order_page.py**: включает методы, необходимые для тестирования процесса заказа самоката.
- **home_page_yandex.py**: содержит методы, взаимодействующие с главной страницей "Яндекс.Дзен".

### Папка tests

- **test_home_page.py**: в этом файле располагаются тесты, проверяющие функциональность главной страницы "Яндекс.Самокат".
- **test_order_page.py**: содержит тесты, относящиеся к страницам заказа самокатов.
- **test_data.py**: включает в себя набор тестовых данных, используемых в тестах.

### Прочие компоненты проекта

- **conftest.py**: файл, где определены и настроены фикстуры, используемые для настройки тестовой среды и управления состоянием тестов.
- **requirements.txt**: файл, содержащий список зависимостей и их версий, необходимых для запуска автотестов.
- **allure_results**: папка, в которой хранятся отчеты о выполнении тестов для дальнейшего анализа с использованием Allure.

## Запуск тестов

Чтобы запустить тесты и сгенерировать отчет, выполните следующие команды:

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите тесты с генерацией результата для Allure
pytest --alluredir=allure_results

# Сгенерируйте отчет Allure в виде HTML
allure serve allure_results
